# Data sources and provenance

Solas uses only openly licensed data. Everything in `public/data/` is generated by
`scripts/prepare_cork_data.py` and committed; the deployed site never queries a data API.
The generated statistics for the current dataset are in [docs/DATASET_REPORT.md](docs/DATASET_REPORT.md).

## Sources

### OpenStreetMap (ODbL 1.0)

© OpenStreetMap contributors — https://www.openstreetmap.org/copyright

Used for:

- **Walking network.** OSMnx's `walk` filter (which excludes motorways, private service roads,
  `foot=no`, roads tagged `sidewalk=separate` because their footways are mapped separately, etc.)
  plus cycleways that explicitly allow pedestrians (`foot=yes|designated|permissive`). Ways tagged
  `access=no|private` without explicit foot permission are removed. Only the largest connected
  network is kept.
- **Lighting evidence.** The `lit` tag on ways, and `highway=street_lamp` nodes.
- **Accessibility-relevant tags.** `highway=steps`, `step_count`, `handrail`, `wheelchair`,
  `incline`, `surface`, `smoothness`, `width`, `sidewalk*`, `tactile_paving`, and on nodes
  `kerb`, `kerb:height`, `crossing`, `barrier`.
- **Landmarks.** Each landmark is an OSM element referenced by id in
  `scripts/config/cork_corridor.json`; its position is fetched from OSM, never typed in.

### OpenFreeMap / OpenMapTiles (basemap only)

Vector tiles and styles from https://openfreemap.org (© OpenMapTiles, data from OpenStreetMap).
The basemap is display-only; it is not used for routing or scoring. Tiles are requested from
OpenFreeMap's servers by the viewer's browser.

## How lighting is classified

Each segment is split into stretches with one class:

| Class | Rule | Confidence |
| --- | --- | --- |
| `mapped_lit` | The way has `lit=yes`, `24/7`, `automatic`, `sunset-sunrise` or `dusk-dawn`. Part-night values (`limited`, `interval`, time ranges) also count but are noted. | Mapped by a contributor |
| `likely_lit` | No `lit` tag, and the stretch is within 30 m of a mapped `highway=street_lamp`. Sampled every 1 m, so one lamp only affects about 60 m of path, never a whole long edge. | Inferred |
| `mapped_unlit` | The way has `lit=no` or `lit=disused`. | Mapped by a contributor |
| `unknown` | No usable evidence. | None. **Unknown is not the same as dark.** |

Limitations:

- A mapped lamp does not prove that the lamp works, that it lights the footway, or that it is on
  at night. That is why lamp proximity is "likely", not "lit".
- OpenStreetMap does not hold Cork City Council's full street-lighting inventory; many lamps are
  missing. We have not found an openly licensed council inventory, so none is used.
- `lit` tags reflect when a contributor last surveyed the street.

## Elevation and slope

No elevation model is used. Slope is **unknown** everywhere except where an OSM `incline` tag
exists (about 4% of network length). Solas does not derive slope from 2D maps.

## What is not used

- No proprietary routing APIs, no API keys, no scraped data.
- No crime, safety or "danger" data. Solas does not claim any route is safe.

## Regenerating

See "Regenerating the Cork data" in the [README](README.md). Overpass responses are cached under
`scripts/.cache/` (ignored by git); use `--refresh` to fetch fresh data.

## Local observations (planned)

A later phase will add an optional, licence-compatible file of hand-verified observations
(for example "steps at this crossing" or "lamp out") with surveyor, date and licence per entry.
These will be shown as local observations, never as city-wide verification.
